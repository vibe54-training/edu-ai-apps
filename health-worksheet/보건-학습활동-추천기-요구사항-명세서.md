# 중학교 3학년 보건 수업용 학습활동 추천기 요구사항 명세서

## 1. 개요

교사가 단원명과 차시 목표를 입력하면 중학교 3학년 보건 수업에 적합한 모둠 활동 3개를 추천하는 도구다. 추천 활동은 카드 형태로 제공한다.

## 2. 사용자와 목적

- **사용자:** 중학교 3학년 보건 교사
- **목적:** 차시 목표에 맞는 모둠 활동과 준비물을 빠르게 계획한다.
- **학생 점수 기록:** 제공하지 않는다.

## 3. 기능 요구사항

### 3.1 입력

교사는 다음 항목을 입력할 수 있어야 한다.

| 항목 | 요구사항 |
|---|---|
| 단원명 | 활동을 계획할 보건 단원의 이름을 입력한다. |
| 차시 목표 | 해당 차시에서 학생이 배우거나 할 수 있어야 하는 내용을 입력한다. |

입력값이 누락된 경우 활동 추천을 진행하지 않고 누락 항목을 안내한다.

### 3.2 활동 추천

- 입력한 단원명과 차시 목표를 반영한 모둠 활동을 **정확히 3개** 추천한다.
- 활동은 중학교 3학년 보건 수업에서 실행할 수 있어야 한다.
- 활동은 학생들이 모둠으로 협력하고 참여할 수 있도록 구성한다.
- 각 활동은 다음 정보를 포함한다.
  - **제목**
  - **준비물**
  - **소요 시간**
  - **진행 방법**
- 진행 방법은 교사가 수업에서 활용할 수 있도록 단계별로 명확하게 작성한다.
- 준비물은 활동에 필요한 항목을 구체적으로 제시한다.
- 소요 시간은 분 단위로 표시한다.

### 3.3 결과 표시

추천된 활동은 **활동별 카드**로 표시한다. 각 카드에 제목, 준비물, 소요 시간, 진행 방법을 구분하여 보여준다.

### 3.4 다시 추천

교사는 같은 단원명과 차시 목표로 활동을 다시 추천받을 수 있어야 한다. 다시 추천해도 활동은 정확히 3개여야 한다.

## 4. 기본 이용 흐름

1. 교사가 단원명을 입력한다.
2. 차시 목표를 입력한다.
3. 활동 추천 버튼을 누른다.
4. 추천된 모둠 활동 3개가 각각 카드 형태로 표시된다.
5. 필요하면 다시 추천받는다.

## 5. 비기능 요구사항

- 입력과 추천 결과를 교사가 쉽게 이해할 수 있도록 구성한다.
- 결과는 화면 크기에 맞춰 읽기 쉽게 표시한다.
- 오류가 발생하면 결과가 생성된 것처럼 표시하지 않고, 이해하기 쉬운 안내를 제공한다.
- 활동은 보건 수업의 교육 목적에 적절하고 학생의 안전과 사생활을 존중하도록 제시한다.

## 6. 제외 범위

초기 버전에는 다음 기능을 포함하지 않는다.

- 학생 점수 기록, 평가 결과 저장 및 성적 관리
- 로그인 및 사용자 계정 관리
- 학생별 활동 참여 기록
- 모둠 편성 및 학생 명단 관리
- 활동 결과물 제출·수집 기능

## 7. 완료 기준

- 단원명과 차시 목표를 입력해 활동 추천을 요청할 수 있다.
- 입력한 내용과 관련된 모둠 활동이 정확히 3개 추천된다.
- 각 활동 카드에 제목, 준비물, 소요 시간, 진행 방법이 표시된다.
- 입력값이 누락되면 적절한 안내가 표시된다.
- 학생 점수 기록 기능이 제공되지 않는다.
